راهنمای جامع دستیار صادرات کیان

سلام بر تیم صادرات عزیز! این دستیار هوش مصنوعی به‌ویژه برای کمک به شما در صادرات کالا از ایران به کشورهای اوراسیا، روسیه و آسیای میانه طراحی شده است.

شخصیت دستیار (کیان)

کیان یک استراتژیست ارشد صادرات با ۲۰ سال تجربه است. او با ابزارهایی مانند ITC Export Potential Map، Trade Map و Market Access Map کار می‌کند و تحلیل‌های عمیقی ارائه می‌دهد. حوزه‌های تخصصی او:

  • محصولات غذایی (پسته، زعفران، خرما، رب گوجه و...)
  • پتروشیمی و مشتقات نفتی (قیر، پلیمر، روغن پایه و...)
  • مبلمان اداری و مدرسه
  • تجهیزات شهری و بازی کودکان

تنظیم کلید API دیپ‌سیک

برای استفاده از دستیار، باید کلید API دیپ‌سیک خود را وارد کنید. این کلید به‌صورت امن در مرورگر شما ذخیره می‌شود و فقط برای ارسال درخواست به سرور دیپ‌سیک استفاده می‌شود. برای دریافت کلید، به سایت دیپ‌سیک مراجعه کنید.

بارگذاری فایل‌ها

می‌توانید فایل‌های PDF، اکسل (xlsx, xls)، فایل‌های متنی و CSV را پیوست کنید. محتوای این فایل‌ها استخراج شده و به پیام شما اضافه می‌شود تا کیان بتواند بر اساس آن‌ها تحلیل کند. این قابلیت برای بررسی لیست محصولات، داده‌های تعرفه‌ای، یا اسناد گمرکی بسیار مفید است.

نحوه استفاده

۱. کلید API را وارد و ذخیره کنید.

۲. در صورت نیاز فایل‌های خود را پیوست کنید.

۳. سؤال یا درخواست خود را به فارسی یا انگلیسی بنویسید و ارسال کنید.

۴. کیان با توجه به شخصیت و دستورالعمل‌های تعریف‌شده، پاسخ تحلیلی و راهبردی ارائه می‌دهد.

نمونه سؤالات

  • «بازار صادرات پسته ایران به قزاقستان و روسیه را مقایسه کن.»
  • «برای صادرات مبلمان اداری به روسیه چه گواهی‌هایی لازم است؟»
  • «یک ایمیل سرد به زبان روسی برای معرفی قیر ایران به یک شرکت ساختمانی بنویس.»
